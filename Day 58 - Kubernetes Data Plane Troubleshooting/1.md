## When Node becomes NotReady

* Run:

  ```bash
  kubectl get nodes
  ```
* Node shows **NotReady**
* Existing pods may still be **Running initially**

---

## What happens to running Pods

* Pods **keep running for some time**
* After **5 minutes**, pods are **evicted**
* Pods move to **Pending** if no other node available

---

## Why Pods get removed after 5 minutes

* Kubernetes adds automatic **taints**:

  * `node.kubernetes.io/not-ready`
  * `node.kubernetes.io/unreachable`
* Default **tolerationSeconds = 300 seconds**
* 300 sec = **5 minutes**
* After 5 min → Pods evicted

---

## How to check Node problem

First check:

```bash
kubectl describe node <node-name>
```

Look for:

* Taints
* Conditions
* Events

---

## Common Cause

* kubelet not running

Check:

```bash
sudo systemctl status kubelet
```

If stopped → Node becomes **NotReady**

---

## Fix

Start kubelet:

```bash
sudo systemctl start kubelet
```

---

## After Fix

Check:

```bash
kubectl get nodes
```

Node becomes:

```
Ready
```

Pods:

```
Running
```

---

## Important Concepts

* kubelet down → Node NotReady
* Node NotReady → No new pods scheduled
* After 5 min → Pods removed
* Scheduler reschedules pods
* If no node → Pods Pending

---

## Troubleshooting Order

1. `kubectl get nodes`
2. `kubectl describe node`
3. Check kubelet:

   ```bash
   systemctl status kubelet
   ```
4. Start kubelet if needed

---

## Key Finding

* kubelet is critical
* If kubelet stops → Node stops working
* Restarting kubelet fixes many issues

---

**Node Unreachable – Key Points (Simple):**

* `node.kubernetes.io/unreachable:NoSchedule`
  → Scheduler **won’t place new Pods** on the node
  → Happens when kubelet heartbeats stop

* `node.kubernetes.io/unreachable:NoExecute`
  → Existing Pods **will be evicted**
  → If they don’t have toleration

* Kubernetes auto-adds:

  ```
  tolerationSeconds = 300
  ```

  → Equals **5 minutes**

* After ~5 minutes:

  * Pods without toleration → **Evicted**
  * Pods → **Rescheduled on other nodes**

* Reason:
  → Controller not receiving **kubelet heartbeats**
  → Node marked **Unreachable**

---

**Summary Flow:**

```
Kubelet stops heartbeats
        ↓
Node = Unreachable
        ↓
No new Pods scheduled
        ↓
Wait 5 minutes
        ↓
Old Pods evicted
        ↓
Pods rescheduled
```
