## What is the difference between ResourceQuota and LimitRange?

### ResourceQuota:
- **Scope:** NAMESPACE level (total across all pods)
- **What it does:** Limits TOTAL resources in the namespace
- **Example:** All pods together cannot use more than 10 CPU
- **Mandatory:** Pods MUST specify resources if quota exists

### LimitRange:
- **Scope:** CONTAINER/POD level (individual)
- **What it does:** Sets min/max/default for INDIVIDUAL containers
- **Example:** Each container must request between 100Mi and 200Mi memory
- **Auto-fill:** If pod doesn't specify resources, default values are applied

### Key Difference:

| Feature | ResourceQuota | LimitRange |
|---------|---------------|-------------|
| **Level** | Namespace (aggregate) | Container/Pod (individual) |
| **Limits** | Total sum across all pods | Per container min/max |
| **Default values** | No | Yes (provides defaults) |
| **Enforcement** | Blocks deployment if exceeded | Validates individual pod specs |
