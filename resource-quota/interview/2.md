## Troubleshooting - Pod Pending Due to Missing Requests with Quota? Pod is not coming up even though image name is correct. Events show `must specify memory` error.

**Root Cause:** A **ResourceQuota** with memory requests/limits is applied on the namespace, but the deployment didn't specify any resource requests/limits.

**Why:** When a ResourceQuota has compute requirements, EVERY pod must specify requests/limits. The quota enforces this.

**Troubleshooting:**
```bash
# Check events
kubectl get events --sort-by='.lastTimestamp'

# Check quota
kubectl describe resourcequota <quota-name>
```

**Solution:** Add resource requests and limits to the deployment:
```yaml
resources:
  requests:
    memory: "50Mi"
    cpu: "100m"
  limits:
    memory: "100Mi"
    cpu: "200m"
```
