## What is the difference between Compute Quota (ResourceQuota for compute) and Resource Quota (Object Count Quota)?

### Compute Quota:
- **Purpose:** Limits CPU and MEMORY usage in a namespace
- **What it controls:** Total amount of CPU and memory that ALL pods combined can request/use
- **Applied on:** Namespace level (via `ResourceQuota` object)
- **Example:** All pods in this namespace can collectively use max 10 CPU cores and 20GB memory

### Resource Quota (Object Count Quota):
- **Purpose:** Limits the NUMBER of API objects/resources created in a namespace
- **What it controls:** Count of pods, services, PVCs, secrets, configmaps, etc.
- **Applied on:** Namespace level (via `ResourceQuota` object)
- **Why needed:** To prevent etcd from growing too large (each object is stored in etcd)
- **Example:** Max 10 pods, 5 services, 3 PVCs in this namespace

### Key Difference:

| Feature | Compute Quota | Resource/Object Count Quota |
|---------|---------------|------------------------------|
| **Limits** | CPU and Memory | Number of API objects |
| **Examples** | `requests.cpu`, `limits.memory` | `count/pods`, `count/services` |
| **Purpose** | Prevent hardware overuse | Prevent etcd overload |
