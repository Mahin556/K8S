### Explain Kubernetes Architecture.

## Kubernetes Architecture

Kubernetes architecture is mainly divided into two parts:

### 1. Control Plane (Cluster Management)

The Control Plane manages the entire Kubernetes cluster and makes global decisions.

* **API Server**

  * Main entry point of Kubernetes.
  * Receives and processes all REST/API requests.

* **etcd**

  * Distributed key-value database.
  * Stores all cluster configuration and state information.

* **Scheduler**

  * Decides on which worker node a Pod should run.
  * Checks resources and policies before scheduling.

* **Controller Manager**

  * Runs controllers to maintain the desired cluster state.
  * Example: Node Controller, Deployment Controller.

---

### 2. Data Plane / Worker Nodes (Workload Execution)

Worker nodes run the actual applications and containers.

* **Kubelet**

  * Agent running on each worker node.
  * Ensures containers are running properly.
  * Communicates with the Control Plane.

* **Kube-proxy**

  * Handles networking and communication between Pods and services.

* **Container Runtime**

  * Responsible for running containers.
  * Examples:

    * `containerd`
    * `CRI-O`

---

### Simple Interview Answer

“Kubernetes architecture consists of two main parts: the Control Plane and Worker Nodes. The Control Plane manages the cluster using components like API Server, etcd, Scheduler, and Controller Manager. Worker nodes run application workloads using Kubelet, Kube-proxy, and a container runtime such as containerd.”
