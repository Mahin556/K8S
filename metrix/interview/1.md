## Metrics Server fails to provide pod and node metrics in a self-managed cluster.

### Troubleshooting Steps:

```bash
# Step 1: Inspect Metrics Server logs
kubectl logs -n kube-system deployment/metrics-server

# Step 2: Verify kubelet arguments
ps aux | grep kubelet

# Step 3: Update Metrics Server deployment
spec:
  containers:
  - name: metrics-server
    args:
    - --kubelet-insecure-tls
```
