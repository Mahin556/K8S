## Your team wants to gradually roll out a new version of an application to a subset of users for testing before fully deploying it. How would you implement a canary deployment?

**Answer:**

### Canary Deployment Setup:

**Step 1: Create Two Deployments**
- **Deployment 1:** Newer version of the application
- **Deployment 2:** Older version of the application

**Step 2: Use Service Mesh for Traffic Control**
- Use **Istio** or **Linkerd** to control routing
- Define rules for traffic percentage:
  - Example: 10% to new version, 90% to old version

**Step 3: Monitor and Evaluate**
- Monitor the new version's performance
- Evaluate metrics before promoting

**Step 4: Gradual Promotion**
- If performance is good, increase traffic to new version
- Eventually route 100% traffic to the new version

### Traffic Flow:
```
Users → Service Mesh (Istio/Linkerd)
         ├── 10% → Deployment 1 (New Version)
         └── 90% → Deployment 2 (Old Version)
```
