#### Q1: What is Kubernetes and what does it do?
**Detailed Answer:**
Kubernetes (K8s) is an open-source **container orchestration platform** originally designed by Google. It abstracts away the underlying infrastructure (servers, networking, storage) and provides a unified API to manage containerized workloads.

**What it does:**
- **Automated Deployment:** Deploys specified container images across a cluster of machines.
- **Self-Healing:** Automatically restarts containers that fail, replaces containers that are unresponsive, and kills containers that fail user-defined health checks.
- **Scaling:** Scales applications up or down based on resource usage (CPU/Memory) or custom metrics using a single command or auto-scaling policies.
- **Service Discovery & Load Balancing:** Gives containers their own IP addresses and a single DNS name for a set of containers, and can load-balance traffic across them.
- **Storage Orchestration:** Allows you to automatically mount persistent storage (local, cloud, or network) to containers.
- **Secret & Configuration Management:** Manages sensitive information (passwords, tokens) and application configuration without rebuilding container images.
