## Question 3: What is the Exact Purpose of Kubernetes?

**Answer:** Kubernetes is an **open-source container orchestration platform** that automates the deployment, scaling, and management of containerized applications.

### Core Purposes:

| Purpose | Description |
|---------|-------------|
| **Automated Deployment** | Deploy containers declaratively using YAML |
| **Scaling** | Auto-scale pods based on CPU/memory/custom metrics |
| **Self-Healing** | Automatically restart failed containers, replace pods |
| **Service Discovery** | DNS-based service discovery and load balancing |
| **Storage Orchestration** | Mount persistent storage (local, cloud, network) |
| **Rolling Updates** | Update applications without downtime |
| **Secret Management** | Securely manage sensitive data |

### The Problem Kubernetes Solves:
- **Without K8s:** Manual deployment, manual scaling, no auto-healing, complex networking
- **With K8s:** Automated everything, declarative configuration, self-healing
