## Question 9: What Are the Stages in a CI/CD Pipeline?

**Answer:** A CI/CD pipeline automates the software delivery process from code commit to production deployment.

### Pipeline Stages:

```
┌─────────┐    ┌────────┐    ┌───────┐    ┌────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  Code   │ → │ Build  │ → │ Test  │ → │  Scan  │ → │  Package │ → │ Deploy   │ → │ Monitor  │
│ Commit  │    │        │    │       │    │        │    │          │    │          │    │          │
└─────────┘    └────────┘    └───────┘    └────────┘    └──────────┘    └──────────┘    └──────────┘
```

| Stage | Description | Tools |
|-------|-------------|-------|
| **1. Code Commit** | Developer pushes code to Git | Git, GitHub, GitLab |
| **2. Build** | Compile code, build artifacts | Maven, Gradle, npm, Docker |
| **3. Test** | Unit tests, integration tests | JUnit, pytest, Selenium |
| **4. Scan** | Security scan, code quality | SonarQube, Trivy, OWASP |
| **5. Package** | Create Docker image, push to registry | Docker, ECR, Harbor |
| **6. Deploy** | Deploy to environments | ArgoCD, Helm, kubectl |
| **7. Monitor** | Verify deployment health | Prometheus, Grafana, Datadog |

### Detailed Pipeline Flow:

**Continuous Integration (CI):**
1. **Code Commit:** Developer pushes to feature branch
2. **Build:** Compile, run unit tests
3. **Code Quality:** SonarQube analysis
4. **Security Scan:** Trivy/Docker Scout image scan
5. **Integration Tests:** Test service interactions
6. **Build Image:** Docker build and push to registry

**Continuous Delivery/Deployment (CD):**
7. **Deploy to Dev:** Automatic deployment
8. **Deploy to Staging:** After approval
9. **Smoke Tests:** Verify critical paths
10. **Deploy to Production:** Canary/Blue-Green strategy
11. **Post-Deployment Monitoring:** Watch metrics and logs

### Kubernetes-Specific CI/CD:
```yaml
# Example: GitHub Actions + ArgoCD
steps:
  - name: Build & Push
    run: |
      docker build -t myapp:${{ github.sha }} .
      docker push myapp:${{ github.sha }}
  
  - name: Update GitOps Repo
    run: |
      cd gitops-repo
      sed -i "s/image:.*/image: myapp:${{ github.sha }}/" deployment.yaml
      git commit -am "Update image to ${{ github.sha }}"
      git push
  
  - name: ArgoCD Sync
    run: argocd app sync my-app
```
