## Swap and System Prerequisites

### Disable Swap
```bash
# Disable swap immediately
swapoff -a

# Check swap status
swapon --show
# or
free -h
```

### Make Swap Disabled Permanent
```bash
# Edit fstab and comment out swap entry
vi /etc/fstab
# Comment the swap line with #
```

### Check SELinux Status
```bash
getenforce
sestatus
```

## Package Installation

### Add Kubernetes Repository
```bash
# Add Kubernetes GPG key and repository
curl -s https://packages.cloud.google.com/apt/doc/apt-key.gpg | apt-key add -
echo "deb https://apt.kubernetes.io/ kubernetes-xenial main" > /etc/apt/sources.list.d/kubernetes.list
```

### Add CRI-O Repository
```bash
# Add CRI-O repository (OS-specific)
# Example for Ubuntu
echo "deb https://download.opensuse.org/repositories/devel:/kubic:/libcontainers:/stable/xUbuntu_20.04/ /" > /etc/apt/sources.list.d/cri-o.list
```

### Update and Install Packages
```bash
# Update package list
apt-get update

# Install all required packages
apt-get install -y kubeadm kubelet kubectl cri-o
```

## Network Prerequisites

### Enable IP Forwarding
```bash
# Check if IP forwarding is enabled
sysctl net.ipv4.ip_forward

# Enable immediately
sysctl -w net.ipv4.ip_forward=1

# Make permanent
echo "net.ipv4.ip_forward = 1" >> /etc/sysctl.conf
sysctl -p
```

### Load Network Filter Module
```bash
modprobe br_netfilter
```

### Check Listening Ports
```bash
# Using netstat
netstat -tlnp | grep 6443

# Using ss
ss -tlnp | grep 6443
```

## Complete Flow Summary Commands

```bash
# === MASTER NODE ===
# 1. Disable swap
swapoff -a
# Comment swap in /etc/fstab

# 2. Install packages
apt-get update
apt-get install -y kubeadm kubelet kubectl cri-o

# 3. Enable services
systemctl enable cri-o --now
systemctl enable kubelet --now

# 4. Enable IP forwarding
sysctl -w net.ipv4.ip_forward=1
modprobe br_netfilter

# 5. Initialize master
kubeadm init --apiserver-advertise-address=<master-ip>

# 6. Set up kubeconfig
mkdir -p ~/.kube
cp /etc/kubernetes/admin.conf ~/.kube/config

# 7. Install Calico CNI
kubectl apply -f https://docs.projectcalico.org/manifests/calico.yaml

# 8. Verify
kubectl get nodes
kubectl get pods -A

# === WORKER NODE ===
# 1. Disable swap
swapoff -a

# 2. Install packages
apt-get install -y kubeadm kubelet cri-o

# 3. Enable services
systemctl enable cri-o --now
systemctl enable kubelet --now

# 4. Join cluster (using command from master)
kubeadm join <master-ip>:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>
```
