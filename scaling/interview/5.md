## Horizontal Pod Autoscaler (HPA) does not scale workloads as expected.

### Troubleshooting Steps:

```bash
# Step 1: Check HPA configuration and metrics
kubectl describe hpa <hpa-name>

# Step 2: Verify pod resource requests and limits
# Should be configured:
resources:
  requests:
    cpu: "250m"
    memory: "256Mi"
  limits:
    cpu: "500m"
    memory: "512Mi"

# Step 3: Check metrics availability
kubectl top pod

# Step 4: Restart metrics server if needed
kubectl rollout restart deployment metrics-server -n kube-system
```

### Common Causes:
- Missing resource limits in deployment
- Metrics server not running
- Wrong metric type configured
