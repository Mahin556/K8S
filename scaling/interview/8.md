## HPA (Horizontal Pod Autoscaler) is configured but pods don't scale even when CPU exceeds the threshold.

### Common Causes:

**1. Metrics Server Not Installed:**
- HPA relies on metrics-server to get CPU/memory metrics
- Without metrics-server, HPA cannot read utilization data

**2. Pods Have No CPU Requests:**
- HPA calculates utilization based on CPU requests
- If requests are not set, HPA can't calculate percentage

**3. Resource Limits Set Incorrectly:**
- Wrong configurations in limits may prevent proper metric calculation

### How to Fix:
```bash
# Install metrics-server
kubectl apply -f metrics-server.yaml

# Define requests and limits in pod spec
resources:
  requests:
    cpu: "200m"
    memory: "256Mi"
  limits:
    cpu: "500m"
    memory: "512Mi"

# Check HPA status
kubectl get hpa
kubectl describe hpa <hpa-name>
```
