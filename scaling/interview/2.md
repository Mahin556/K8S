### How does Kubernetes handle container scaling?

Kubernetes handles scaling mainly through the **Horizontal Pod Autoscaler (HPA)**.

HPA automatically increases or decreases the number of Pod replicas based on resource usage such as:

* CPU utilization
* Memory usage
* Custom metrics

### How It Works

* If application load increases:

  * Kubernetes creates more Pods.
* If load decreases:

  * Kubernetes removes extra Pods.

This helps:

* Improve application performance
* Maintain high availability
* Optimize resource usage

### Example

If CPU usage goes above 65%, HPA automatically scales the Deployment from:

* Minimum Pods: `3`
* Maximum Pods: `5`

---

### HPA Example Configuration

```yaml id="3v8n2"
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler

metadata:
  name: my-hpa

spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: my-deployment

  minReplicas: 3
  maxReplicas: 5

  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 65
```
