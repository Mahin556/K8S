### "What is your experience with Kubernetes?"

#### Infrastructure Details:
- **Number of clusters:** At least 2 (Test/Staging + Production), sometimes Dev cluster as well
- **Cluster type:** On-premises (VMware, physical servers) vs Cloud-managed (EKS, GKE, AKS)
- **Node counts:** 
  - Production: 3 Master Nodes + ~22 Worker Nodes
  - Test: 3 Master Nodes + ~22 Worker Nodes
  - Dev: 1 Master Node + ~8 Worker Nodes (for learning/training)

#### Storage Solutions:
- **On-premises:** GlusterFS (NAS/File storage - Red Hat storage solution)
- **Cloud (AWS):** 
  - EFS for NAS (file system storage)
  - EBS for SAN (block storage)

#### Networking Solutions:
- **On-premises:** Calico CNI
- **Cloud (AWS):** Amazon VPC CNI (native, no Calico needed)

#### Deployment Methods:
- **Helm Charts** stored in a repository server
- **Jenkins integration** - Jenkins jobs trigger Helm deployments (not manual)
- Daily activities: Troubleshooting pod restarts, checking pod events, storage expansion

#### Monitoring:
- **Prometheus & Grafana** for resource monitoring
- **Wireshark** for packet-level network troubleshooting (in telecom)
