Alternatives for Non-StatefulSet Workloads 
If you are using Deployments, ReplicaSets, or DaemonSets, you must use one of the following methods for storage: 

1. Shared Persistent Volumes: Manually create one PVC and reference it in your Deployment. All replicas will share the same volume (useful for  volumes like NFS). 
2. Ephemeral Volumes: Use  or other ephemeral types for temporary storage that does not survive pod restarts. 
3. Pre-provisioned PVCs: Manually create a PVC for each anticipated pod and bind them (impractical for auto-scaling). [3, 4, 8, 9, 10]
