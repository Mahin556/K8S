### Deploy a 3-node database cluster where each node must be reachable by predictable hostname. Pods must keep identity after restart. Other pods must connect using stable hostnames, not pod IPs.

**Solution:**

```yaml
apiVersion: v1
kind: Service
metadata:
  name: db-cluster
  labels:
    app: db-cluster
spec:
  clusterIP: None                       # Headless service - no load balancing
  selector:
    app: db-cluster
  ports:
  - port: 3306
    targetPort: 3306
    name: mysql
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: db-cluster
spec:
  serviceName: db-cluster               # MUST match headless service name
  replicas: 3                           # Exactly 3 database nodes
  selector:
    matchLabels:
      app: db-cluster
  template:
    metadata:
      labels:
        app: db-cluster
    spec:
      containers:
      - name: mysql
        image: mysql:8.0
        ports:
        - containerPort: 3306
        env:
        - name: MYSQL_ROOT_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-secret
              key: password
        volumeMounts:
        - name: mysql-data
          mountPath: /var/lib/mysql
  volumeClaimTemplates:
  - metadata:
      name: mysql-data
    spec:
      accessModes:
      - ReadWriteOnce
      resources:
        requests:
          storage: 20Gi
```

**How Other Pods Connect:**

```yaml
# Application pod connecting to specific database nodes
apiVersion: v1
kind: Pod
metadata:
  name: app-client
spec:
  containers:
  - name: app
    image: myapp:latest
    env:
    # Connect to specific nodes using stable DNS names
    - name: DB_NODE_0
      value: "db-cluster-0.db-cluster.default.svc.cluster.local"
    - name: DB_NODE_1
      value: "db-cluster-1.db-cluster.default.svc.cluster.local"
    - name: DB_NODE_2
      value: "db-cluster-2.db-cluster.default.svc.cluster.local"
    # Or use the headless service for discovery
    - name: DB_CLUSTER
      value: "db-cluster"
```

**DNS Resolution:**
```bash
# Each pod gets its own DNS record
db-cluster-0.db-cluster.default.svc.cluster.local  → Pod IP
db-cluster-1.db-cluster.default.svc.cluster.local  → Pod IP
db-cluster-2.db-cluster.default.svc.cluster.local  → Pod IP

# Headless service returns all pod IPs (SRV records)
nslookup db-cluster
# Returns IPs of all 3 pods
```

**Key Points:**
- **StatefulSet** ensures pods have stable ordinal names (0, 1, 2)
- **Headless Service** (`clusterIP: None`) creates individual DNS A records
- Each pod reachable via: `<pod-name>.<service-name>.<namespace>.svc.cluster.local`
- Stable identity survives pod restarts and rescheduling
- No load balancing - direct pod-to-pod communication
- Other applications connect using hostnames, not IPs
- Essential for distributed databases (Cassandra, MongoDB, MySQL cluster)
