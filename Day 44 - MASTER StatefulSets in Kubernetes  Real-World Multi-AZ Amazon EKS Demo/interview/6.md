## You have a StatefulSet application with 5 replicas on 3 nodes. One pod is stuck in Pending state. What could be the issue?

### What is StatefulSet?
- Used for stateful applications like databases
- Data must be persisted and synced between pods
- Requires sequential pod naming and stable identities

### Common Causes:

**1. Insufficient Resources:**
- CPU or memory not available on any node
- Check with `kubectl describe pod <pod-name>`

**2. PVC/PV Binding Issues:**
- StatefulSets usually need PersistentVolumeClaims per replica
- If no matching PV exists in the correct zone or node, the pod won't schedule
- PVC is **mandatory** for StatefulSets

**3. Node Affinity Issues:**
- Pod may have node affinity rules that don't match available nodes
- Zone restrictions may prevent scheduling

**4. Storage Class Mismatch:**
- PVC requesting a storage class that doesn't match available PVs

### How to Fix:
```bash
# Check events
kubectl describe pod <pod-name>

# Check PVC status
kubectl get pvc

# Check PV availability
kubectl get pv

# Ensure enough PVs with correct storage class exist
# Ensure no affinity/zone restrictions blocking scheduling
```
