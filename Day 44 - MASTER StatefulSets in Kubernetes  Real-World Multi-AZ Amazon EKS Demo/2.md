# 1️⃣ StorageClass (EBS – RWO)

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: ebs-sc
provisioner: ebs.csi.aws.com
volumeBindingMode: WaitForFirstConsumer
reclaimPolicy: Delete
allowVolumeExpansion: true
parameters:
  type: gp3
```

# 2️⃣ Deployment + Manually Created PVC (Shared PVC Model)

### PVC

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: app-shared-pvc
spec:
  accessModes:
    - ReadWriteOnce
  storageClassName: ebs-sc
  resources:
    requests:
      storage: 5Gi
```

### Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: app-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
        - name: web
          image: nginx
          volumeMounts:
            - name: data
              mountPath: /usr/share/nginx/html
      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: app-shared-pvc
```

⚠️ If replicas >1 and RWO storage → Multi-Attach error.

# 3️⃣ StatefulSet + volumeClaimTemplates (Correct DB Pattern)

### Headless Service (Required for STS)

```yaml
apiVersion: v1
kind: Service
metadata:
  name: mysql-headless
spec:
  clusterIP: None
  selector:
    app: mysql
  ports:
    - port: 3306
```

### StatefulSet

```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql
spec:
  serviceName: mysql-headless
  replicas: 3
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      containers:
        - name: mysql
          image: mysql:8
          env:
            - name: MYSQL_ROOT_PASSWORD
              value: password
          ports:
            - containerPort: 3306
          volumeMounts:
            - name: mysql-data
              mountPath: /var/lib/mysql
  volumeClaimTemplates:
    - metadata:
        name: mysql-data
      spec:
        accessModes:
          - ReadWriteOnce
        storageClassName: ebs-sc
        resources:
          requests:
            storage: 10Gi
```

This creates:

* mysql-data-mysql-0
* mysql-data-mysql-1
* mysql-data-mysql-2

Each pod gets its own PVC.

### PVC

```yaml
apiVersion: v1
```


# 5️⃣ PodDisruptionBudget (For HA)

```yaml
apiVersion: policy/v1
kind: PodDisruptionBudget
metadata:
  name: mysql-pdb
spec:
  minAvailable: 2
  selector:
    matchLabels:
      app: mysql
```

Prevents voluntary eviction below 2 pods.

# 6️⃣ Anti-Affinity (Node-Level HA)

```yaml
spec:
  affinity:
    podAntiAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
        - labelSelector:
            matchExpressions:
              - key: app
                operator: In
                values:
                  - mysql
          topologyKey: "kubernetes.io/hostname"
```

Ensures:

* Pods are placed on different nodes.

---

# 7️⃣ Topology Spread Constraint (Zone-Level HA)

```yaml
topologySpreadConstraints:
  - maxSkew: 1
    topologyKey: topology.kubernetes.io/zone
    whenUnsatisfiable: DoNotSchedule
    labelSelector:
      matchLabels:
        app: mysql
```

Spreads pods across AZs.

# 8️⃣ Example RWX Storage (EFS/NFS Style)

If using RWX storage:

```yaml
accessModes:
  - ReadWriteMany
```

Then multiple pods can mount same PVC.

Used for:

* Shared file systems
* Not recommended for databases

---

# 9️⃣ Reclaim Policy Behavior

In StorageClass:

```yaml
reclaimPolicy: Retain
```

* PVC deleted → PV remains
* Manual cleanup required

```yaml
reclaimPolicy: Delete
```

* PVC deleted → PV deleted automatically

---

# 🔟 Scaling Behavior Summary

StatefulSet:

* Scale up → new PVC created
* Scale down → PVC NOT deleted
* Delete STS → PVCs remain

Deployment:

* Delete Deployment → Pods deleted
* PVC remains only if created separately

---

# 🔥 Real DevOps Mental Model

Use Deployment when:

* Stateless app
* Shared config
* No stable identity

Use StatefulSet when:

* Database
* Kafka
* Elasticsearch
* Needs stable storage
* Needs ordered startup
