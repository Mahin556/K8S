### Multi-Architecture Docker Images

```bash
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  -t myrepo/app:latest \
  --push .
```

**Verify multi-arch manifest:**
```bash
docker manifest inspect <image>
```

**Restrict scheduling to matching nodes:**
```yaml
nodeSelector:
  kubernetes.io/arch: amd64
```
