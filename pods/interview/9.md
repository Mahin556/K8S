#### Q12: Suppose a pod exceeds its memory limit. What signal will be sent to the process?
**Detailed Answer:**
- **Mechanism:** The Linux Kernel's **OOM Killer** (Out-of-Memory Killer) intervenes.
- **Signal:** The process receives **SIGKILL** (Signal 9).
- **Implication:** The process is terminated **immediately** and **cannot catch or ignore this signal**.
- **Kubernetes Behavior:**
    1. Container exceeds `spec.containers[].resources.limits.memory`.
    2. Kernel kills the container process.
    3. Container runtime reports exit code `137` (128 + 9).
    4. Kubernetes restarts the container according to `restartPolicy` (usually `Always`).
    5. `kubectl describe pod` will show `OOMKilled` status.
