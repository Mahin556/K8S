### As a DevOps engineer, you need to configure a Spring Boot application to run as a single-container pod exposing port 8080.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: spring-boot-app
spec:
  containers:
  - name: spring-boot-app-container
    image: your-repo/spring-boot-app:1.0
    ports:
    - containerPort: 8080
```
