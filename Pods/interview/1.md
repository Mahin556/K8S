### What is the difference between a Pod and a container?

| Container                                             | Pod                                                                                          |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| A container is a single isolated application process. | A Pod is the smallest deployable unit in Kubernetes that can contain one or more containers. |
| It runs a specific application or service.            | It acts as a logical host for containers.                                                    |
| Containers are lightweight and isolated.              | Pods manage and group tightly coupled containers together.                                   |
| A container has its own filesystem and process.       | Containers inside a Pod share network and storage resources.                                 |
| Containers can run independently.                     | Kubernetes manages, schedules, and scales Pods, not individual containers.                   |
| Example: A single Docker container running Nginx.     | Example: A Pod containing an application container and a logging sidecar container.          |

### Simple Interview Answer

“A container is a single isolated application process, while a Pod is a Kubernetes object that groups one or more related containers together. Containers inside the same Pod share networking and storage resources, and Kubernetes manages Pods instead of individual containers.”
