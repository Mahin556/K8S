
#### Scenario 4: You upgraded the Kubernetes cluster version. Now, a critical application is crashing (CrashLoopBackOff).
**Detailed Troubleshooting Path:**
1.  **Check API Deprecations:** The most common cause. Kubernetes v1.22 removed `extensions/v1beta1` Ingress APIs. If your YAML uses old `apiVersion`, the deployment will fail or the controller won't recognize it.
2.  **Container Runtime Compatibility:** Ensure the Container Runtime (containerd) version is compatible with the new Kubelet version.
3.  **Pod Security Standards (PSS):** In v1.25+, PodSecurityPolicy was removed. If you used PSP, you need to migrate to **Pod Security Admission** (enforce/audit/warn levels).
4.  **Check Logs:** `kubectl logs <pod-name> --previous` (to see logs from the *crashed* container before restart).
