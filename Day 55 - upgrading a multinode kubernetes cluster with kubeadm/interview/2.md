#### Scenario 3: How do you perform maintenance on a K8s node without downtime?
**Detailed Answer (Node Drain Workflow):**
1.  **Cordon:** `kubectl cordon <node-name>`
    - **Effect:** Marks node as **unschedulable**. No *new* pods will be placed here.
2.  **Drain:** `kubectl drain <node-name> --ignore-daemonsets --delete-emptydir-data`
    - **Effect:** Evicts all existing pods from the node gracefully (SIGTERM, then SIGKILL after `terminationGracePeriodSeconds`).
    - **DaemonSets:** `--ignore-daemonsets` allows drain to proceed because DaemonSet pods are expected to run on every node.
    - **StatefulSets:** Drain respects PodDisruptionBudgets (PDB). If draining violates PDB, drain will fail.
3.  **Maintenance:** Perform OS updates, kernel patching, docker daemon upgrade.
4.  **Uncordon:** `kubectl uncordon <node-name>`
    - **Effect:** Makes the node available for scheduling again.
