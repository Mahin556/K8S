## What authentication method does the superuser use to log in to the API server for the first time?

**Answer:** **Certificate-based authentication**

- The `kubernetes-admin` user authenticates using a client certificate
- This certificate is embedded in `/etc/kubernetes/admin.conf`
- Alternative authentication methods include:
  - Service Account Tokens (for pods)
  - OpenID Connect (OIDC) tokens
  - Webhook token authentication
  - Static password file (not recommended)
