### Brief the Kubernetes architecture

#### How to Answer (2-4 minutes):

**Start with the basics:**
- Kubernetes is an open-source container orchestration tool
- Two main components: **Control Plane** (Master Node) and **Data Plane** (Worker Nodes)

**Control Plane Services (4 services):**

| Service | Role |
|---------|------|
| **kube-apiserver** | Front-end, validates all instructions, handles authentication/authorization |
| **etcd** | Cluster database, stores all cluster state (key-value store) |
| **kube-scheduler** | Decides which node a pod should run on |
| **kube-controller-manager** | Continuously monitors and reconciles desired state vs running state |

**Worker Node Services (3 services):**

| Service | Role |
|---------|------|
| **Container Runtime** | CRI-O or containerd - runs containers |
| **kubelet** | Receives instructions from apiserver, manages pods on the node |
| **kube-proxy** | Handles network rules for pod/service communication |

**Additional Architecture Components:**
- **CoreDNS** - Internal DNS resolution for service discovery
- **CNI (Calico)** - Provides IP addresses to pods
- **Ingress Controller** - Application-level load balancer (HTTP/HTTPS)
- **MetalLB** - Network-level load balancer for on-premises (TCP/IP)
