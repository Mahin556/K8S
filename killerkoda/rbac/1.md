## 🔐 Create ServiceAccount, Role, and RoleBinding for Pod Access

We need to:
1. Create a ServiceAccount named `app-account`.
2. Create a Role named `app-role-cka` that allows `get` permissions on `pods` in the `default` namespace.
3. Create a RoleBinding named `app-role-binding-cka` that binds the Role to the ServiceAccount.

---

## ✅ Step-by-Step Commands

### 1️⃣ Create the ServiceAccount

```bash
kubectl create serviceaccount app-account
```

### 2️⃣ Create the Role

```bash
kubectl create role app-role-cka \
  --verb=get \
  --resource=pods \
  --namespace=default
```

### 3️⃣ Create the RoleBinding

```bash
kubectl create rolebinding app-role-binding-cka \
  --role=app-role-cka \
  --serviceaccount=default:app-account \
  --namespace=default
```

---

## 🔍 Verification

### Check the ServiceAccount

```bash
kubectl get serviceaccount app-account
```

### Check the Role

```bash
kubectl get role app-role-cka -n default -o yaml
```

### Check the RoleBinding

```bash
kubectl get rolebinding app-role-binding-cka -n default -o yaml
```

### Test Permissions (as the ServiceAccount)

To verify that the service account can only `get` pods, run:

```bash
kubectl auth can-i get pods \
  --as=system:serviceaccount:default:app-account \
  -n default
```

Expected output:
```
yes
```

Test other verbs to confirm restrictions:

```bash
kubectl auth can-i list pods \
  --as=system:serviceaccount:default:app-account \
  -n default
```

Expected output:
```
no
```

---

## 📋 Summary of Created Resources

| Resource | Name | Purpose |
| :--- | :--- | :--- |
| **ServiceAccount** | `app-account` | The identity that will be used by the application/pod. |
| **Role** | `app-role-cka` | Defines the permissions: `get` on `pods` in the `default` namespace. |
| **RoleBinding** | `app-role-binding-cka` | Binds the Role (`app-role-cka`) to the ServiceAccount (`app-account`) in the `default` namespace. |

---

## 🧹 Cleanup (Optional)

To delete all created resources:

```bash
kubectl delete serviceaccount app-account
kubectl delete role app-role-cka -n default
kubectl delete rolebinding app-role-binding-cka -n default
```
