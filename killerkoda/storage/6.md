## 📦 Provision Storage with PV, PVC, and Pod

We'll create:
1. **PersistentVolume** `my-pv-cka` (100Mi, hostPath, standard storage class)
2. **PersistentVolumeClaim** `my-pvc-cka` (100Mi request, standard storage class)
3. **Pod** `my-pod-cka` (nginx) mounting the PVC at `/var/www/html`

---

### ✅ Step 1 – Create the Host Directory

```bash
sudo mkdir -p /mnt/data
```

---

### ✅ Step 2 – Create PersistentVolume `my-pv-cka`

```bash
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: PersistentVolume
metadata:
  name: my-pv-cka
spec:
  capacity:
    storage: 100Mi
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Retain
  storageClassName: standard
  hostPath:
    path: /mnt/data
EOF
```

---

### ✅ Step 3 – Create PersistentVolumeClaim `my-pvc-cka`

```bash
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: my-pvc-cka
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 100Mi
  storageClassName: standard
EOF
```

---

### ✅ Step 4 – Deploy Pod `my-pod-cka` Using the PVC

```bash
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: my-pod-cka
  labels:
    app: nginx
spec:
  containers:
  - name: nginx
    image: nginx:latest
    volumeMounts:
    - name: storage
      mountPath: /var/www/html
  volumes:
  - name: storage
    persistentVolumeClaim:
      claimName: my-pvc-cka
EOF
```

---

### ✅ Step 5 – Verify All Resources

**Check PV status:**
```bash
kubectl get pv my-pv-cka
```

**Check PVC status:**
```bash
kubectl get pvc my-pvc-cka
```

**Check Pod status:**
```bash
kubectl get pod my-pod-cka
```

**Check all together:**
```bash
kubectl get pv,pvc,pod
```

### 🔍 Verify Volume Mount

Check that the volume is mounted correctly:

```bash
kubectl exec my-pod-cka -- df -h | grep /var/www/html
```

Test by writing a file:

```bash
kubectl exec my-pod-cka -- sh -c "echo 'Hello from Nginx' > /var/www/html/index.html"
kubectl exec my-pod-cka -- cat /var/www/html/index.html
```

Expected output:
```
Hello from Nginx
```

You can also verify on the host:

```bash
sudo cat /mnt/data/index.html
```

### 🧹 Cleanup (Optional)

To delete all resources:

```bash
kubectl delete pod my-pod-cka
kubectl delete pvc my-pvc-cka
kubectl delete pv my-pv-cka
```

---

### 📝 Important Notes

- **Binding**: The PVC `my-pvc-cka` will bind to `my-pv-cka` because they share:
  - Same `storageClassName: standard`
  - Same `accessModes: ReadWriteOnce`
  - PVC request `100Mi` matches PV capacity `100Mi` exactly
  - `hostPath` PV is manually provisioned (static provisioning)
- **Pod Scheduling**: Since `hostPath` does not have `nodeAffinity`, the Pod can be scheduled on any node. If the Pod lands on a different node from where `/mnt/data` exists, it will fail. In a multi-node cluster, you should add `nodeAffinity` to the PV to restrict it to a specific node.
- **Waiting Time**: Binding and pod startup may take up to 1-2 minutes – please be patient.
