## ✅ Final Solution: Gateway API Canary Deployment

### 📌 The Requirement
- **Namespace:** `hawkins`  
- **HTTPRoute name:** `stranger-canary-route`  
- **Gateway:** `stranger-gw` (in `str-gtw`)  
- **Host:** `api.stranger.things`  
- **Path:** `/recommendations` (prefix match)  
- **Backends:** `stv-v1` (port `8080`, weight `90`) and `stv-v2` (port `8080`, weight `10`)

---

### 📄 The Applied Manifest (`/root/st-canary.yaml`)
```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: stranger-canary-route
  namespace: hawkins
spec:
  parentRefs:
  - name: stranger-gw
    namespace: str-gtw
  hostnames:
  - "api.stranger.things"
  rules:
  - matches:
    - path:
        type: PathPrefix
        value: "/recommendations"
    backendRefs:
    - name: stv-v1
      port: 8080
      weight: 90
    - name: stv-v2
      port: 8080
      weight: 10
```

---

### 🚀 Deployment & Verification Commands

#### Apply the route
```bash
kubectl apply -f /root/st-canary.yaml
```

#### Check the HTTPRoute status
```bash
kubectl get httproute stranger-canary-route -n hawkins
```
Expected output shows `Accepted` in the `status` conditions.

#### Inspect the weights with `jsonpath` (exam‑friendly)
```bash
kubectl get httproute stranger-canary-route -n hawkins -o jsonpath='{range .spec.rules[*].backendRefs[*]}{.name}{" "}{.weight}{"\n"}{end}'
```
Output:
```
stv-v1 90
stv-v2 10
```

#### Verify Gateway acceptance
```bash
kubectl describe gateway stranger-gw -n str-gtw | grep -A5 Routes
```
You should see `stranger-canary-route` listed.

### 📘 Why This Matters – Canary Deployment Benefits

| Feature | Value |
|--------|-------|
| **Risk** | Low – only a small subset of users are exposed |
| **Rollback** | Instant – just change the weight to `0` or delete the route |
| **Validation** | Real traffic, real metrics (latency, errors, logs) |
| **Gradual rollout** | Increase weight from 10% → 50% → 100% as confidence grows |
| **Comparison** | Safer than a big‑bang switch (blue/green), more controlled than a rolling update |
