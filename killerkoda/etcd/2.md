The error `Error: unknown flag: --data-dir` occurs because in **etcd v3.6**, the `snapshot restore` subcommand has been **removed** from `etcdctl` and moved to the separate binary **`etcdutl`**. 

Your current `etcdctl` binary only handles `snapshot save`. To restore a snapshot, you must use `etcdutl`.

Additionally, you used `--data-dir=/root/`, but the requirement explicitly asks for `--data-dir /root/default.etcd` (note the full path).

Here is the exact command that will work:

```bash
etcdutl snapshot restore /opt/cluster_backup.db --data-dir /root/default.etcd 2>&1 | tee restore.txt
```

---

### 🔍 Why this fixes it

- **`etcdutl`** is the dedicated maintenance utility for etcd (used for restore, defrag, etc.).
- **`--data-dir /root/default.etcd`** writes the restored etcd data files to the correct directory.
- **`2>&1 | tee restore.txt`** captures both standard output and standard error into the `restore.txt` file, as required.

After running this, check that the restore succeeded:

```bash
ls -l /root/default.etcd
```

You should see etcd data files (like `member/`) inside that directory, and `restore.txt` will contain the console output from the restore process.
