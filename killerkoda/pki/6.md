Here’s a clear, step‑by‑step solution to extract the required information from the kubeconfig file `/opt/course/1/kubeconfig`. All commands are provided with explanations, and we include both the `kubectl`‑native and `jq`‑based approaches for flexibility.

---

### Task 1 – Extract All Context Names
Write each context name (one per line) into `/opt/course/1/contexts`.

**Using `kubectl config view` + jsonpath (range loop):**
```bash
kubectl config view -ojsonpath='{range .contexts[*]}{.name}{"\n"}{end}' \
  --kubeconfig /opt/course/1/kubeconfig > /opt/course/1/contexts
```

**Alternative using `kubectl config get-contexts`:**
```bash
kubectl config get-contexts --kubeconfig=/opt/course/1/kubeconfig -o name > /opt/course/1/contexts
```

---

### Task 2 – Extract the Current Context
Write the name of the currently active context into `/opt/course/1/current-context`.

**Using jsonpath:**
```bash
kubectl config view -ojsonpath='{.current-context}' \
  --kubeconfig /opt/course/1/kubeconfig > /opt/course/1/current-context
```

**Using dedicated command:**
```bash
kubectl config current-context --kubeconfig=/opt/course/1/kubeconfig > /opt/course/1/current-context
```

---

### Task 3 – Extract and Decode Client Certificate for `account-0027`
Retrieve the base64‑encoded client certificate for user `account-0027`, decode it, and save the resulting PEM certificate into `/opt/course/1/cert`.

**Using `kubectl config view` with a filtered jsonpath (preferred):**
```bash
kubectl config view --raw -ojsonpath='{.users[?(@.name=="account-0027")].user.client-certificate-data}' \
  --kubeconfig /opt/course/1/kubeconfig | base64 -d > /opt/course/1/cert
```

**Using `jq` for better readability (if installed):**
```bash
kubectl config view --kubeconfig=/opt/course/1/kubeconfig --raw -o json \
  | jq -r '.users[] | select(.name=="account-0027") | .user."client-certificate-data"' \
  | base64 -d > /opt/course/1/cert
```

---

### Verification
Check that the generated files contain the expected data:

```bash
echo "=== Contexts ==="
cat /opt/course/1/contexts

echo "=== Current Context ==="
cat /opt/course/1/current-context

echo "=== Certificate (first few lines) ==="
head -5 /opt/course/1/cert
```

Optionally validate the certificate using OpenSSL:
```bash
openssl x509 -in /opt/course/1/cert -text -noout | head -20
```

---

### Explanation of jsonpath expressions

| Expression | Purpose |
|------------|---------|
| `{range .contexts[*]}{.name}{"\n"}{end}` | Iterate over all contexts and print each `name` followed by a newline. |
| `{.current-context}` | Directly access the `current-context` field. |
| `{.users[?(@.name=="account-0027")].user.client-certificate-data}` | Filter the `users` array for the entry with name `account-0027`, then retrieve the `client-certificate-data` under `user`. The `--raw` flag is required to see the actual base64 data (otherwise it is shown as `DATA+OMITTED`). |
