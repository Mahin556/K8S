## Question 3: Web Page Not Accessible Despite Pod Running

**Scenario:** NGINX web server deployed successfully, but the web page is not accessible. Find out why.

### Troubleshooting Steps:

**Step 1: Check Pod Events**
```bash
kubectl describe pod <pod-name>
# Look for any issues - if none found, pod is healthy
```

**Step 2: Check Web Server Logs**
```bash
kubectl logs <pod-name>
# Look for any startup errors
```

**Step 3: Check Web Server Configuration Inside the Container**
```bash
kubectl exec -it <pod-name> -- cat /etc/nginx/conf.d/default.conf
```
Note the port the server is listening on (typically port 80 for NGINX).

**Step 4: Check Service Configuration**
```bash
kubectl describe svc <service-name>
```

### Example Issue Found:
- NGINX is listening on **port 80**
- Service `targetPort` is set to **8080** (mismatch!)

### Solution - Edit the Service:
```bash
kubectl edit svc <service-name>
```
Change `targetPort` from `8080` to `80`. Changes are applied automatically.

### Verify:
```bash
kubectl describe svc <service-name>
# Confirm targetPort is now 80

# Test access
curl localhost:<node-port>
```

### Debugging Checklist:
1. Describe the pod → Check events
2. Check logs → Look for errors
3. Exec into container → Verify application config
4. Check service → Verify port mappings
5. Test connectivity → Use curl to validate
