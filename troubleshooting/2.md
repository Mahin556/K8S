## A cluster node is in `NotReady` state, disrupting workloads. Pods cannot be created or services are unavailable.

### Troubleshooting Steps:

```bash
# Step 1: Describe the node to identify issues
kubectl describe node <node-name>

# Step 2: Check kubelet logs for errors
journalctl -u kubelet

# Step 3: Verify disk and memory usage
kubectl top node <node-name>

# Step 4: Drain the node and restart services
kubectl drain <node-name> --ignore-daemonsets --force
sudo systemctl restart kubelet
```

### Common Causes:
- Dangling Docker images consuming disk space
- kubelet service issues
- Resource pressure on node
