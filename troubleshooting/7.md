## Question 4: Pod Crashed - Data Lost - How to Make Volume Persistent?

**Scenario:** An NGINX pod with custom configuration crashed, and the `index.html` file was deleted. How to avoid similar events in the future?

### The Solution: Persistent Volumes (PV) and Persistent Volume Claims (PVC)

### Key Concepts:

**PersistentVolume (PV):**
- A piece of storage in the cluster
- Provisioned by an administrator or dynamically created using StorageClasses
- Independent of pod lifecycle - data survives pod crashes

**PersistentVolumeClaim (PVC):**
- A request for storage by a user
- Contains parameters: StorageClass, AccessMode, Storage size
- Kubernetes matches PVC to an appropriate PV (binding)

### Practical Implementation:

**Step 1: Create a Directory on the Node**
```bash
sudo mkdir -p /mnt/data
```

**Step 2: Create a PersistentVolume (PV)**
```yaml
# pv.yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: my-pv
spec:
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Retain
  storageClassName: manual
  hostPath:
    path: /mnt/data
```

```bash
kubectl apply -f pv.yaml
kubectl get pv
```

**Step 3: Create a PersistentVolumeClaim (PVC)**
```yaml
# pvc.yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: my-pvc
spec:
  storageClassName: manual
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 500Mi
```

```bash
kubectl apply -f pvc.yaml
kubectl get pvc
# Status should show: Bound
```

**Note:** Even though 500Mi was requested, the entire 1Gi PV was allocated because it was the closest match.

**Step 4: Create a Pod Using the PVC**
```yaml
# pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pv-pod
spec:
  containers:
  - name: nginx
    image: nginx
    volumeMounts:
    - name: persistent-storage
      mountPath: /usr/share/nginx/html
  volumes:
  - name: persistent-storage
    persistentVolumeClaim:
      claimName: my-pvc
```

```bash
kubectl apply -f pod.yaml
```

**Step 5: Verify Persistence**
```bash
# Copy a file to the mounted path
cp index.html /mnt/data/

# Check if file is visible inside the container
kubectl exec -it nginx-pv-pod -- ls /usr/share/nginx/html
kubectl exec -it nginx-pv-pod -- cat /usr/share/nginx/html/index.html

# Delete the pod
kubectl delete pod nginx-pv-pod

# Check if data still exists on the node
ls /mnt/data/
# File is still there! Data is persistent!
```
