
## Scenario 3: Optimizing Resource Utilization

**Question:** Your firm wants to optimize resource utilization. How would you use Kubernetes to manage resources effectively?

### Three Key Things to Explain:

**1. Resource Requests and Limits:**
- Define `requests` (guaranteed minimum) and `limits` (maximum allowed) for each container
- Prevents pods from using more than specified resources

**2. Auto-Scaling:**
- **Horizontal Pod Autoscaler (HPA):** Increases/decreases number of replicas
- **Vertical Pod Autoscaler (VPA):** Adjusts CPU/memory for existing pods

**3. Monitoring:**
- Use **Prometheus** and **Grafana** for dashboards
- Gain insights into CPU, memory, and filesystem usage

### How to Answer in English:
"To optimize resource utilization in Kubernetes, I would start by defining resource requests and limits for each container in my pod. Requests ensure that each pod gets a guaranteed amount of CPU and memory, while limits prevent a pod from using more than the specified amount of resources. Next, I would implement Horizontal Pod Autoscaling and Vertical Pod Autoscaling to adjust the resource requests and limits for the containers in the pod. Additionally, I would monitor cluster resources using tools like Prometheus and Grafana to gain insights about what is going on in my cluster."
