## What can you do to increase security in Kubernetes?

**Answer:**

### Key Security Measures:

**1. RBAC (Role-Based Access Control):**
- Narrow down permissions
- Control which pod can access/communicate with which other pod

**2. Namespaces:**
- Create different namespaces for different teams/environments
- Pods in Namespace-A cannot access pods in Namespace-B

**3. Network Policies:**
- Limit communication between pods
- By default, pods should not communicate freely
- Set policies for privileged containers

**4. Audit Logging:**
- Turn on audit logging to track activities
- Monitor who is doing what in the cluster
