## Your organization operates in a regulated industry and needs to ensure compliance with security and privacy regulations. How would you implement compliance and governance?

### Compliance and Governance Controls:

**1. Kubernetes Native Security Controls:**
- **Pod Security Policies** - Define security rules
- **Network Policies** - Control communication
- **RBAC** - Role-Based Access Control

**2. Enforce Regulatory Requirements:**
- Implement policies for security and privacy regulations

**3. Auditing and Logging:**
- Enable audit logging
- Keep track of all activities in the cluster
- Maintain historical data for compliance purposes

### Summary:
"Use native Kubernetes security controls to enforce policies, and enable auditing and logging to monitor and track all activities for compliance."
