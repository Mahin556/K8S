## What are init containers and why do we need them?

### What are Init Containers?
Init containers are containers that run to **complete a specific activity before the startup** of your actual/main container.

### Key Characteristics:
- Run before the main application container starts
- Run to completion (must finish before main container starts)
- You can use multiple init containers
- They run sequentially, one after another

### Use Cases:

**1. Volume Mounting:**
- Mount a specific volume before the main application starts

**2. Setup Tasks:**
- Perform initialization tasks like database migrations

**3. Waiting for Dependencies:**
- Wait for a service or database to be ready before starting the app

**4. Permission Setup:**
- Set file permissions or create directories

### Example:
```yaml
spec:
  initContainers:
  - name: init-setup
    image: busybox
    command: ['sh', '-c', 'echo "Initializing..." && sleep 10']
  containers:
  - name: main-app
    image: my-app:latest
```
