### What is Sidecar-Container.

A Sidecar Container is a helper or auxiliary container that runs alongside the main application container inside the same Pod.

It supports the main application by providing additional features without modifying the application itself.

Both containers share:
  * Network
  * Storage volumes
  * Pod resources

#### Common Use Cases

* Log forwarding
* Monitoring and metrics collection
* Service mesh proxies (like Envoy)
* TLS/SSL termination
* Data synchronization

#### Example

A Pod may contain:
  * Main container → Running the application
  * Sidecar container → Collecting and forwarding logs

#### Benefits

* Separation of concerns
* Reusable helper services
* Easier monitoring and security management
* Better modular design

#### Simple Interview Answer

“A sidecar container is a secondary helper container that runs with the main application container in the same Kubernetes Pod. It provides supporting features like logging, monitoring, proxying, or security without changing the main application code.”
