## Question 2: Pod Status is Pending - Troubleshooting

**Scenario:** You created an NGINX pod, but the status is `Pending`. How do you find out why?

### Troubleshooting Steps:

**Step 1: Check Pod Status**
```bash
kubectl get pods
```

**Step 2: Describe the Pod**
```bash
kubectl describe pod <pod-name>
```

**Step 3: Analyze the Events Section**
Look for warnings or errors in the events section of the describe output.

### Example Error Found:
```
Warning: FailedScheduling
0/1 nodes are available: 1 node(s) had untolerated taint
```

### Root Cause:
The master node has a taint `node-role.kubernetes.io/master:NoSchedule` by default, which prevents regular pods from being scheduled on it.

### How to Check Node Taints:
```bash
kubectl describe node <node-name> | grep -i taint
```

### Solution - Remove the Taint:
```bash
kubectl taint node <node-name> node-role.kubernetes.io/master:NoSchedule-
# Or for all nodes:
kubectl taint nodes --all node-role.kubernetes.io/master:NoSchedule-
```

**Note:** The `-` at the end removes the taint.

### Verify:
```bash
kubectl get pods
# Pod should now be Running
kubectl describe pod <pod-name>
# Events should show: Created container, Started container
```
