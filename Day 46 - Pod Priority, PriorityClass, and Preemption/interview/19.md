## What is the difference between `nodeName` and `nodeSelector`?

### nodeName:
- **Specific single node** selection
- You specify the exact node name (e.g., `worker-2`)
- Only ONE node possibility
- **No failover** - If that node goes down, pod stays pending
- **No redundancy**

### nodeSelector:
- **Multiple node** selection based on labels
- You specify a label (e.g., `disk=ssd`)
- Multiple nodes can match the label
- **Failover possible** - If one node fails, pod can schedule on another matching node
- **Redundancy** built-in

### When to use:
- `nodeName`: Only when you absolutely need a specific node (bypasses scheduler)
- `nodeSelector`: When you want a type/category of nodes with failover capability
