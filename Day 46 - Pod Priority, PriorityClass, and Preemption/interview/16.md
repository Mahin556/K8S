### When to Use Pod Affinity (Real Scenario):

**Problem:** Web service pod scheduled on Node-1, but Redis pod (which caches data for the web service) gets scheduled on Node-2. This creates network latency because Redis has to be accessed remotely.

**Solution:** Use **Pod Affinity** to couple them together:
- Redis and Web service should always run on the **same node**
- This reduces latency because they communicate locally
