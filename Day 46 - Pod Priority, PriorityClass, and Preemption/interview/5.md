## Pods are not scheduled on available nodes due to taints, tolerations, or affinity rules.

### Troubleshooting Steps:

```bash
# Step 1: Check pod events
kubectl describe pod <pod-name>

# Step 2: List taints on nodes
kubectl describe node <node-name>

# Step 3: Add tolerations to pod spec
tolerations:
- key: "node.kubernetes.io/memory-pressure"
  operator: "Exists"
  effect: "NoSchedule"

# Step 4: Review affinity rules
affinity:
  nodeAffinity:
    requiredDuringSchedulingIgnoredDuringExecution:
      nodeSelectorTerms:
      - matchExpressions:
        - key: "disktype"
          operator: In
          values:
          - ssd
```

### Common Causes:
- Misconfigured nodeSelector
- Missing tolerations for node taints
- Affinity rules not matching
