## YAML Manifest Debugging (CKAD-Style Question)

**Scenario:** You are given a deployment manifest with intentional mistakes. Deploy it and fix the errors.

**Mistake 1: Wrong API Version**
```yaml
# Wrong:
apiVersion: apps/v1beta1  # or incorrect version

# Check available versions:
kubectl api-resources | grep deployment

# Correct:
apiVersion: apps/v1
```

**Mistake 2: Selector Labels Mismatch**
```yaml
# Wrong:
spec:
  selector:
    matchLabels:
      app: nginx-app     # Different from template labels
  template:
    metadata:
      labels:
        app: nginx        # Different!

# Correct (must match):
spec:
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
```

**Mistake 3: Missing Selector**
- Deployment **requires** a selector
- Unlike ReplicationController (RC), which can auto-derive selectors, Deployment cannot
- If selector is missing → error
