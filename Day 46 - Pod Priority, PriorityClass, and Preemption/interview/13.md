## What is the difference between Node Affinity and Pod Affinity? Where would you use each?

### Node Affinity:
  - **Purpose:** Rules about which **NODE** a pod should or should not run on
  - **Use case:** "I want my pod to run on nodes with specific characteristics (e.g., SSD disks, GPU, specific region/zone)"
  - **Example:** Run this application only on nodes in the `india` region with `SSD` disks
  - **Node Anti-Affinity:** "I do NOT want my pod to run on certain types of nodes"

### Pod Affinity:
  - **Purpose:** Rules about which **PODS** should be placed near or far from each other
  - **Use case:** "I want these two pods to run close together (or  far apart)"
  - **Example:** Redis should always run on the same node as the web application to reduce latency
  - **Pod Anti-Affinity:** "I do NOT want two Redis pods on the same node"
