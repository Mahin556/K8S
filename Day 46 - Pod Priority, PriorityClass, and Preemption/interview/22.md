## Troubleshooting Pod Scheduling Issues

**Scenario:** A junior team member's pod is not getting scheduled. How would you guide them to troubleshoot?

**Answer:**

**Step 1: Describe the Pod**
```bash
kubectl describe pod <pod-name> -n <namespace>
```

**Step 2: Analyze the Output**
- Check CPU and memory assignments
- Check if resources are sufficient
- Look for error messages

**Common Reasons for Pod Not Starting:**
- Insufficient memory
- CPU limits too low
- Not enough replicas configured
- Resource constraints
- Node affinity/taint issues

**Step 3: Fix Based on Findings**
- Increase memory/CPU limits
- Increase replica count
- Adjust resource requests
