## Troubleshooting a Pod Stuck in `Pending` State - 2 (Node Selector Mismatch)? A `test-deployment` is stuck in `Pending`. You need to find the root cause.

**Error Message:** `0/4 nodes are available: 1 node(s) had untolerated taint, 3 node(s) didn't match Pod's node affinity/selector.`

**Root Cause:** The deployment was configured with a `nodeSelector` for a label (e.g., `disk=ssd`) that no node has.

**Commands for Troubleshooting:**

1.  **Check Pod Events:**
    ```bash
    kubectl describe pod <pod-name>
    ```

2.  **Check Node Labels:**
    ```bash
    kubectl get nodes --show-labels
    ```
    To find a specific label value, you can use:
    ```bash
    kubectl get nodes -l disk=ssd
    ```

3.  **Add the Required Label to a Node:**
    ```bash
    kubectl label nodes worker-2 disk=ssd
    ```
