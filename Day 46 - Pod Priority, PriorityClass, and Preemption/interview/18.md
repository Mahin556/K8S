## What is the difference between Node Selector and Taint/Toleration? When would you use each?

### Node Selector:
- **Purpose:** "I WANT my pod to run on specific nodes"
- **Mechanism:** Pod SELECTS nodes based on labels
- **Tenancy Model:** **Shared Tenancy** - Other pods can also run on the same node
- **Example:** Label 3 nodes with `tier=web` and use nodeSelector to ensure web pods only go there. But other pods can also be scheduled on those nodes.

### Taint/Toleration:
- **Purpose:** "I want to PREVENT pods from running on this node unless they have special permission"
- **Mechanism:** Node REPELS pods; only pods with matching toleration can land
- **Tenancy Model:** **Dedicated Tenancy** - Reserve a node for exclusive use
- **Example:** Taint a node with `critical=true:NoSchedule` and add toleration only to critical pods. No other pods can run there.

### Key Difference:

| Feature | Node Selector | Taint/Toleration |
|---------|---------------|------------------|
| **Direction** | Pod CHOOSES node | Node REPELS pods |
| **Tenancy** | Shared (others can also run) | Dedicated (exclusive use) |
| **Prevention** | Cannot prevent other pods | Prevents all pods without toleration |

### Important Dependency:
- **Toleration depends on Node Selector** - If you want a pod to run on a specific tainted node, you need BOTH:
  1. **Toleration** (to be allowed on the tainted node)
  2. **Node Selector** (to actually be directed to that node)
- Toleration alone says "I'm allowed to run there" but doesn't force the pod to go there. Node Selector forces it.
