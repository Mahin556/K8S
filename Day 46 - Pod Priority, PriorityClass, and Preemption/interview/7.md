### Pod Scheduling Failure in Multi-AZ Cluster

**Error:** `0/12 nodes are available: 3 node(s) had volume node affinity conflict, 5 node(s) didn't match node selector, 4 node(s) had taints.`

**Troubleshooting:**
```bash
kubectl describe pod <pod-name>
kubectl describe pv <pv-name>
kubectl get nodes --show-labels
kubectl describe node <node>
```

**Fixes:** Adjust nodeSelector, add tolerations, ensure PVC zone matches node zone.
