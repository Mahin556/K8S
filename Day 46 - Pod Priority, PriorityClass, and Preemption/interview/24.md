## Troubleshooting a Pod Stuck in `Pending` State - 3 (Tainted Nodes)? - A new deployment named `demo` with the `nginx` image is stuck in `Pending`?

**Error Message:** `0/3 nodes are available: 3 node(s) had untolerated taint {node.kubernetes.io/unreachable}.`

**Root Cause:** All three worker nodes were tainted with a custom taint (e.g., `red=true:NoSchedule`), and the pod does not have the required toleration.

**Commands for Troubleshooting:**

1.  **Describe the Pod:**
    ```bash
    kubectl describe pod <pod-name>
    ```
    This will show a warning about tainted nodes.

2.  **Check Node Taints:**
    ```bash
    kubectl describe node <node-name> | grep Taints
    ```

3.  **Remove Taint from a Node:**
    ```bash
    kubectl taint nodes worker-2 red=true:NoSchedule-
    ```

4.  **Add Toleration to Pod Spec:**
    ```yaml
    spec:
      tolerations:
      - key: "red"
        operator: "Equal"
        value: "true"
        effect: "NoSchedule"
    ```
