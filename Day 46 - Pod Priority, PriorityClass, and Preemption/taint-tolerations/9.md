```bash

What We’ll Demonstrate
----------------------
• A node has a NoExecute taint
• A Pod has a toleration with tolerationSeconds
• The Pod will run for some time, then be evicted


Step 1 — Add a Taint to a Node
------------------------------

kubectl taint nodes workerine key1=value1:NoExecute

Meaning:
• Pods without toleration → immediately evicted
• Pods with tolerationSeconds → stay for limited time


Step 2 — Pod YAML with tolerationSeconds
----------------------------------------

kubectl apply -f -<<EOF
apiVersion: v1
kind: Pod
metadata:
  name: taint-demo
spec:
  containers:
  - name: nginx
    image: nginx
  tolerations:
  - key: "key1"
    operator: "Equal"
    value: "value1"
    effect: "NoExecute"
    tolerationSeconds: 60
EOF

What Happens?
-------------
• Pod is scheduled on the tainted node
• It tolerates the taint
• It runs for 60 seconds
• After 60 seconds → Kubernetes evicts the Pod


Important Concept
-----------------
• NoSchedule → Pod will NOT schedule
• PreferNoSchedule → Avoid scheduling if possible
• NoExecute →
    - Evicts existing Pods
    - Prevents new Pods
    - tolerationSeconds works ONLY with this effect


Real-World Use Case
-------------------
• Node becomes NotReady
• Kubernetes automatically adds:
    node.kubernetes.io/not-ready:NoExecute
• System Pods tolerate for 300 seconds
• After timeout → eviction happens
```
