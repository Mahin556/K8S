# 🔹 1️⃣ Deployment WITHOUT Topology Spread

### `without-depone.yaml`

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: spread
spec:
  replicas: 3
  selector:
    matchLabels:
      type: spread
  template:
    metadata:
      labels:
        type: spread
    spec:
      containers:
      - name: pause
        image: lovelearnlinux/webserver:v1
```

### Apply

```bash
kubectl apply -f without-depone.yaml
```

# 🔹 2️⃣ Deployment WITH Topology Spread

### `with-depone.yaml`

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: spread
spec:
  replicas: 3
  selector:
    matchLabels:
      type: spread
  template:
    metadata:
      labels:
        type: spread
    spec:
      topologySpreadConstraints:
      - maxSkew: 1
        topologyKey: kubernetes.io/hostname
        whenUnsatisfiable: ScheduleAnyway
        labelSelector:
          matchLabels:
            type: spread
      containers:
      - name: pause
        image: lovelearnlinux/webserver:v1
```

### Apply

```bash
kubectl apply -f with-depone.yaml
```

# 🔹 3️⃣ Scale Deployment

```bash
kubectl scale deployment spread --replicas=6
```

Check distribution:


# 🔹 4️⃣ Remove a Node

### On Manager

```bash
kubectl drain <node-name> --ignore-daemonsets --delete-emptydir-data
kubectl delete node <node-name>
```

### On Worker Node

```bash
kubeadm reset -f
```

# 🔹 5️⃣ Install Descheduler (Using Helm)

### Add Repo

```bash
helm repo add descheduler https://kubernetes-sigs.github.io/descheduler/
helm repo update
```

### Install

```bash
helm install my-release --namespace kube-system descheduler/descheduler
```

Check CronJob:

```bash
kubectl -n kube-system get cronjobs
```

# 🔹 7️⃣ Full Descheduler Policy (Example)

Replace policy.yaml section with this:

```yaml
apiVersion: "descheduler/v1alpha1"
kind: "DeschedulerPolicy"

strategies:

  LowNodeUtilization:
    enabled: true
    params:
      nodeResourceUtilizationThresholds:
        targetThresholds:
          cpu: 50
          memory: 50
          pods: 50
        thresholds:
          cpu: 20
          memory: 20
          pods: 20

  RemoveDuplicates:
    enabled: true

  RemovePodsHavingTooManyRestarts:
    enabled: true
    params:
      podRestartThreshold: 100
      includingInitContainers: true

  RemovePodsViolatingInterPodAntiAffinity:
    enabled: true

  RemovePodsViolatingNodeAffinity:
    enabled: true
    params:
      nodeAffinityType:
      - requiredDuringSchedulingIgnoredDuringExecution

  RemovePodsViolatingNodeTaints:
    enabled: true

  RemovePodsViolatingTopologySpreadConstraint:
    enabled: true
```

Save and exit.

# 🔹 9️⃣ Add New Node

On Manager:

```bash
kubeadm token create --print-join-command
```

Copy the output and run it on new worker node.

After joining:

```bash
kubectl get nodes
```

Check pod redistribution:

```bash
kubectl get pods -o wide --sort-by=.spec.nodeName
```

You will see:

* Pods automatically moved
* Load balanced
