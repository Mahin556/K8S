## What are IPIP Mode and VXLAN Mode in Calico?

**Answer:** These are two **protocols** used for cross-node pod communication.

### IPIP Mode (IP-in-IP):
- **Default mode** in Calico
- Encapsulates IP packets within IP packets
- Creates a tunnel between nodes
- Used when the underlying network supports IP-in-IP

### VXLAN Mode:
- Alternative to IPIP
- Used when IP-in-IP is blocked/disabled
- Example: Azure blocks IP-in-IP communication
- In such cases, VXLAN is used instead

### Key Point:
- Calico uses **IPIP mode by default**
- If `vxlan` shows as `Never`, it means VXLAN is not being used
- The choice between IPIP and VXLAN depends on the underlying network infrastructure
- This is typically a network engineer's decision
