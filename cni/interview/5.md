## How to Check the Calico Network Configuration?

### Commands:

**1. Check IP Pool (Cluster-wide CIDR range):**
```bash
kubectl get ippool
```
This shows the CIDR range for the entire cluster.

**2. Check IPAM Blocks (Per-node subnet allocation):**
```bash
kubectl get ipamblocks
```
This shows how the large CIDR is broken into smaller subnets and allocated to each node.

### Key Concepts:

**CIDR vs Block Size:**
- **CIDR:** The entire cluster's IP range (e.g., `172.16.0.0/16`)
- **Block Size:** The subnet size allocated to each node (e.g., `/26`)
- The large CIDR is subnetted into smaller blocks
- Each node gets its own subnet block
- Example: `/16` network subnetted on `/26` basis → one `/26` block per node

**Why subnetting?**
- A single large network cannot be allocated to one worker node
- Multiple worker nodes need their own IP ranges
- Subnetting breaks the large network into smaller chunks
- Each chunk is assigned to a different node
