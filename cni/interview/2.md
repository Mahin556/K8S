## Does Calico Run on Master Node? Why?

**Answer:** YES, Calico runs on Master Node too.

**Reasons:**
1. Pods run on the master node (in `kube-system` namespace)
2. Control plane services are also pods that need IP addresses
3. Future services like monitoring (Prometheus), logging, etc., may run on master node
4. Without Calico on master node, those pods won't get IP addresses
