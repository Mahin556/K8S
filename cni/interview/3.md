## What is Calico and What Are Its Key Features?

### Key Features of Calico:

**1. Layer 3 Networking:**
- Provides both switching AND routing
- Containers on different nodes can communicate directly via IP
- No need for port forwarding between nodes

**2. BGP Protocol Based:**
- Uses Border Gateway Protocol for routing
- BGP is a standard routing protocol used in large networks
- Allows virtual network to integrate with physical routers (especially in Telecom)

**3. Network Policy Rules:**
- By default, all containers can communicate with each other internally
- Network Policies allow you to define rules:
  - Which pods can communicate with which pods
  - Which traffic is allowed IN (ingress)
  - Which traffic is allowed OUT (egress)
- This feature was NOT available in Flannel or Weave
- This provides internal cluster security

**4. BGP Integration with Physical Network:**
- In Telecom, BGP is the preferred routing protocol
- Calico's virtual network can be made visible to physical routers via BGP
- This connects your container network with physical infrastructure
