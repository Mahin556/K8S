### How can you achieve communication between Pods in different Nodes?

In Kubernetes, Pods running on different nodes can communicate with each other using the cluster’s internal networking.

Kubernetes provides a flat networking model where:

* Every Pod gets its own IP address.
* Pods can communicate directly using internal IPs without NAT.

This communication is enabled by:

* Container Network Interface (CNI) plugins
* Virtual network overlay

### Common Kubernetes Network Plugins

* Calico
* Flannel
* Cilium

### Communication Flow

```text id="5m2p8"
Pod (Node A) ↔ Virtual Network ↔ Pod (Node B)
```

### Key Point

By default, Kubernetes allows Pod-to-Pod communication across nodes unless restricted by Network Policies.

### Simple Interview Answer

“In Kubernetes, Pods on different nodes communicate using the cluster’s internal networking and virtual network overlay provided by CNI plugins. Each Pod gets a unique IP address, allowing direct communication across nodes.”
