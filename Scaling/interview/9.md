## Cluster Autoscaler Not Scaling

**Scenario:** Cluster Autoscaler is enabled, but pods remain in Pending state.

### Common Causes:

**1. Pod Requests Exceeding Node Size:**
- Pod requests more CPU/memory than any node can provide
- Even a new node wouldn't be able to fit the pod

**2. Node Affinity or Taints:**
- Pod has affinity rules or tolerations that don't match new nodes
- Prevents scheduling on newly created nodes

**3. Autoscaler Limits Reached:**
- `--max-nodes` limit configured and already reached
- Resource quotas preventing new node creation

### How to Fix:
```bash
# Check autoscaler logs
kubectl logs -n kube-system <autoscaler-pod>

# Adjust pod resource requests
resources:
  requests:
    cpu: "200m"
    memory: "256Mi"

# Check node pools and limits
kubectl get nodes
kubectl describe configmap cluster-autoscaler-status -n kube-system

# Relax affinity/taints if needed
```
