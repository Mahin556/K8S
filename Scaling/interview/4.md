## Your application experiences varying levels of traffic throughout the day. How would you implement auto-scaling to handle increased demand automatically?

**Answer:**

### Using Horizontal Pod Autoscaler (HPA):

**What HPA Does:**
- Automatically scales the number of pod replicas
- Based on real-time resource utilization metrics

**Configuration:**
- Define target resource utilization metrics:
  - **CPU utilization** (e.g., 80%)
  - **Memory utilization**
- Define scaling behavior:
  - Minimum and maximum replicas
  - When to scale up/down

**How It Works:**
- HPA continuously monitors metrics
- When CPU reaches 80%, HPA increases replicas
- When utilization drops, HPA decreases replicas
- Ensures application handles varying traffic automatically
