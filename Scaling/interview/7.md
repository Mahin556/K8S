## What is the difference between Vertical Scaling and Horizontal Scaling?

### Vertical Scaling:
- **Meaning:** Increasing resources of EXISTING pod/container
- **How:** Change CPU/memory limits of running container
- **Analogy:** Upgrading from 1GB to 2GB RAM on same machine
- **Kubernetes:** Change `resources.requests/limits` in deployment

### Horizontal Scaling:
- **Meaning:** Increasing NUMBER of pods/replicas
- **How:** Increase replica count
- **Analogy:** Adding more machines instead of upgrading one
- **Kubernetes:** `kubectl scale deployment --replicas=5`
- **Auto-scaling:** HPA (Horizontal Pod Autoscaler)

### Key Difference:

| Feature | Vertical Scaling | Horizontal Scaling |
|---------|------------------|---------------------|
| **Direction** | Up/Down (resources) | Out/In (replicas) |
| **Resource** | Change CPU/Memory limits | Change replica count |
| **Kubernetes** | Edit deployment resources | `kubectl scale` or HPA |
| **Auto object** | VPA (Vertical Pod Autoscaler) | HPA (Horizontal Pod Autoscaler) |
