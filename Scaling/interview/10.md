## An SRE team wants to increase the number of servers and scale their platform. How can Kubernetes help?

**Simple Answer:**

"Kubernetes helps SRE teams scale in three main ways:

**First, automatic pod scaling.** When traffic increases and CPU goes above a threshold we set—say 70%—Kubernetes automatically creates more pods within seconds. When traffic drops, it removes them. No manual work needed.

**Second, automatic node scaling.** If the pods can't fit on existing nodes, Kubernetes asks the cloud provider to add more servers automatically. This means the platform scales itself from application to infrastructure without human intervention.

**Third, visibility.** We use Prometheus to collect metrics and Grafana to see dashboards. This tells us how resources are being used, when to plan for more capacity, and what's happening in real time.

The result is that the SRE team doesn't need to manually add servers during traffic spikes. The system handles it automatically, costs are optimized because we only use what we need, and the team can focus on more important work instead of firefighting."
