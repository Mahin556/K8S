## You are draining a node for patching or maintenance. Some pods are stuck in "Terminating" state and won't go away.

### Common Causes:

**1. Pods Without Replicas:**
- Bare pods or DaemonSets don't have replicas to reschedule
- These pods have nowhere to go when evicted

**2. PodDisruptionBudget (PDB) Issues:**
- PDB defines minimum number of pods that must remain available
- If eviction would violate PDB, Kubernetes prevents pod deletion

**3. Finalizers/Webhooks:**
- Finalizers or admission webhooks may be blocking pod deletion
- They wait for some cleanup operation to complete

### What is PodDisruptionBudget?
PDB defines how many pods of an application can be **voluntarily disrupted** at a time during maintenance operations. This prevents all pods from being evicted simultaneously, which would cause application downtime.

### How to Fix:
```bash
# Check PDB
kubectl get pdb

# Force delete a pod (use with caution)
kubectl delete pod <pod-name> --force --grace-period=0

# Add PDB to control disruption
```

**⚠️ Caution:** Force deleting a pod during active transactions may cause data loss.
