## Difference Between ReplicaSet and ReplicationController

**Question:** What is the difference between ReplicaSet (RS) and ReplicationController (RC)?

### ReplicationController (RC) - Older:
- Only supports **equality-based** selector
- Can only match exact key-value pairs
- Example: `app = nginx` (only one value)

### ReplicaSet (RS) - Newer:
- Supports BOTH:
  1. **Equality-based** selectors (like RC)
  2. **Set-based** selectors (more expressive)
- Set-based operators: `In`, `NotIn`, `Exists`, `DoesNotExist`
- Example: `environment In (production, staging)` (multiple values)

### Key Difference:
- **RC:** `matchLabels` only (equality)
- **RS:** `matchLabels` (equality) AND `matchExpressions` (set-based)

### Practical Impact:
```yaml
# ReplicationController - Only this:
selector:
  app: nginx

# ReplicaSet - Can also do this:
selector:
  matchLabels:
    app: nginx
  matchExpressions:
  - {key: environment, operator: In, values: [production, staging]}
  - {key: tier, operator: NotIn, values: [frontend]}
```
