## Rolling Updates in Kubernetes Deployment

A rolling update is a deployment strategy used to update applications gradually without downtime.

### How It Works

1. The Deployment creates a new ReplicaSet with the updated configuration.

   * Example:

     * New container image version

2. Kubernetes gradually:

   * Scales up new Pods
   * Scales down old Pods

3. The process continues step-by-step until:

   * All old Pods are replaced
   * All updated Pods are running successfully

---

## Benefits

* Zero or minimal downtime
* Smooth application updates
* Easy rollback if issues occur
* Maintains application availability

---

## Example

If a Deployment has 5 Pods:

* Kubernetes replaces Pods one by one (or in batches)
* Users continue accessing the application during the update

---

### Simple Interview Answer

“In Kubernetes, rolling updates work by creating a new ReplicaSet with the updated configuration and gradually replacing old Pods with new Pods. This ensures application updates happen with minimal or no downtime.”
