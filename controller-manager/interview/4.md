### Explain the difference between a StatefulSet and a Deployment.

| StatefulSet                                                       | Deployment                                              |
| ----------------------------------------------------------------- | ------------------------------------------------------- |
| Used for managing **stateful applications**.                      | Used for managing **stateless applications**.           |
| Provides stable Pod names and persistent identities.              | Pods are interchangeable and do not keep identity.      |
| Supports persistent storage for each Pod.                         | Storage is usually temporary or shared.                 |
| Each Pod gets a unique network identity.                          | Pods get random names and can change anytime.           |
| Pods are created and deleted in order.                            | Pods are created and terminated in parallel.            |
| Suitable for databases and applications requiring stable storage. | Suitable for web applications, APIs, and microservices. |
| Examples: MySQL, MongoDB, Cassandra.                              | Examples: Nginx, frontend apps, REST APIs.              |

### Simple Interview Answer

“In Kubernetes, a Deployment is used for stateless applications where Pods are interchangeable, while a StatefulSet is used for stateful applications that require stable identities, ordered deployment, and persistent storage.”
