### Explain the differences between a DaemonSet and a ReplicaSet. ReplicaSet

| ReplicaSet                                                             | DaemonSet                                               |
| ---------------------------------------------------------------------- | ------------------------------------------------------- |
| Ensures a specified number of Pod replicas are running in the cluster. | Ensures one Pod runs on every node (or selected nodes). |
| Pods can run on any node.                                              | Automatically runs Pods on all cluster nodes.           |
| Mainly used for stateless applications.                                | Mainly used for node-level services.                    |
| Maintains desired replica count.                                       | Maintains one Pod per node.                             |
| Example: Web applications, APIs.                                       | Example: Log collectors, monitoring agents.             |

---

## Example Use Cases

### ReplicaSet

* Nginx web servers
* Frontend applications
* REST APIs

### DaemonSet

* Fluentd
* Monitoring agents
* Node exporters

---

## Simple Interview Answer

“A ReplicaSet ensures a specific number of Pods are running in the Kubernetes cluster, while a DaemonSet ensures that a copy of a Pod runs on every node in the cluster.”
