## Question 5: Node Affinity + Taints/Tolerations - Big Data Nodes

**Scenario:** 
1. Big Data app pods should be placed ONLY on Big Data nodes
2. No OTHER application pods should be deployed on Big Data nodes

### Solution: Combination of Node Affinity and Taints/Tolerations

### Part 1: Node Affinity (Attract Pods to Nodes)

**Purpose:** Ensures pods are placed on specific nodes based on labels.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: big-data-app
spec:
  affinity:
    nodeAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
        nodeSelectorTerms:
        - matchExpressions:
          - key: node-type
            operator: In
            values:
            - big-data
  containers:
  - name: app
    image: big-data-app:latest
```

**Limitation:** Node Affinity CANNOT prevent other pods from being scheduled on the same node.

### Part 2: Taints and Tolerations (Repel Unwanted Pods)

**Taint:** Applied to the node to repel pods
**Toleration:** Applied to pods to allow them on tainted nodes

**Analogy from the video:**
- A toddler is playing in a garden
- Mom sprays mosquito repellent on the toddler
- The toddler is now **tainted** (mosquitoes can't bite)
- Some mosquitoes are **tolerant** to the spray and can still bite

**Step 1: Add a Taint to the Big Data Node**
```bash
kubectl taint nodes <big-data-node> node-type=big-data:NoSchedule
```

**Step 2: Add Toleration to Big Data Pods**
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: big-data-app
spec:
  tolerations:
  - key: "node-type"
    operator: "Equal"
    value: "big-data"
    effect: "NoSchedule"
  affinity:
    nodeAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
        nodeSelectorTerms:
        - matchExpressions:
          - key: node-type
            operator: In
            values:
            - big-data
  containers:
  - name: app
    image: big-data-app:latest
```

### How They Work Together:

| Concept | Purpose | Direction |
|---------|---------|-----------|
| **Node Affinity** | Attracts specific pods TO nodes | Pod → Node |
| **Taint** | Repels all pods FROM nodes | Node → Pod |
| **Toleration** | Allows specific pods on tainted nodes | Pod → Node |

### Result:
- Big Data pods have **both** toleration (to bypass taint) and node affinity (to target the node)
- Other pods without toleration cannot be scheduled on the tainted Big Data node
