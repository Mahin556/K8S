### Monitoring dashboard shows no traffic/metrics for Nginx web servers, but application team says everything is running fine.

- Solution - Deploy Test Pod with Labels:
  ```yaml
  apiVersion: v1
  kind: Pod
  metadata:
    name: test-nginx
    labels:
      application: nginx
      environment: production
  spec:
    containers:
    - name: nginx
      image: nginx:latest
  ```

- Apply and Verify:
  ```bash
  kubectl apply -f test-pod.yaml
  ```

- Troubleshooting Steps:
  - Deploy a test pod matching production Nginx service labels.
  - Add labels: application: nginx and environment: production.
  - Check if test pod metrics appear in Prometheus/dashboard.
  - If test pod metrics appear but original app metrics don't → escalate to application team.
  - The issue is likely with the application's metric exposure, not Kubernetes infrastructure.

- Key Points:
  - Labels are crucial for service discovery and monitoring.
  - Service monitors/ Prometheus use labels to discover targets.
  - Mismatched or missing labels prevent metric collection.
  - Use kubectl get pods --show-labels to verify labels.
