
## How do you get centralized logs from pods?

**Answer:** Three methods:

**1. Node-Level Logging Agent:**
- Provides information at node level
- Logs are collected from all pods on the node

**2. Grafana Dashboard with Loki:**
- Integrated with Kubernetes
- Can view logs for past 7, 8, or any number of days
- Centralized dashboard for log viewing

**3. Streaming Sidecar Containers:**
- Sidecar container streams logs directly
- Can export logs from the application directly
- Also accessible from pod details (three dots menu in Kubernetes dashboard)
