## What are the challenges you face with Prometheus for monitoring your Kubernetes cluster?

**1. High Availability (HA) Support:**
- Prometheus provides HA, but it's not a very good solution
- If your single Prometheus data source goes down, your monitoring stops

**2. Integration with Grafana:**
- When you enable HA for Prometheus, Grafana can't easily pick up information from multiple Prometheus data sources
- You need to configure a load balancer with sticky sessions
- All information must go to a single data source from which Grafana collects data
- This is a complicated setup

**3. The Solution - Thanos:**
- Thanos is a Cloud Native Computing Foundation (CNCF) project
- Effectively solves the Prometheus HA problem
- Provides a better way to handle multiple Prometheus instances
- Currently maturing but a very effective solution
