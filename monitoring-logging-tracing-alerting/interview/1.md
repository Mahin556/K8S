## Your team needs visibility into the performance and health of applications running in Kubernetes. How would you implement application observability?

**Answer:**

### Observability Stack:

**1. Metrics Collection:**
- Use **Prometheus** as the data source
- Collect metrics from applications and infrastructure

**2. Visualization:**
- Use **Grafana** to visualize the data
- Create dashboards for monitoring

**3. Logging:**
- Use Kubernetes events and logs for troubleshooting

**4. Distributed Tracing:**
- Use tools like:
  - **Jaeger**
  - **Zipkin**
- Provides end-to-end visibility into request flow
- Track how requests move through microservices
