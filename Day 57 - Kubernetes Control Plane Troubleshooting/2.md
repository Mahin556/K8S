**If API is reachable (kubectl works):**

* Use `kubectl describe` → check events
* Use `kubectl logs -f` → live logs
* Use `kubectl logs --previous` → last crash logs
* Control-plane pods are **static pods**
* Static pods appear as **mirror pods**
* Names look like: `kube-<component>-<nodeName>`
* Example: `kube-apiserver-control-plane`
* Check those pod names for issues

**If API is NOT reachable:**

* Check node directly
* View logs: `/var/log/containers/`
* Run: `crictl ps -a` → see containers
* Check kubelet logs: `journalctl -u kubelet`
