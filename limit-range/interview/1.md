## Troubleshooting - Pod Pending Due to Limit Range - Deployment is not running. The error shows request/limit exceeding something?

**Root Cause:** A **LimitRange** is applied on the namespace with:
- Min: 100Mi memory
- Max: 200Mi memory
- The deployment requested 400Mi, which exceeds the max limit

**What is LimitRange?**
- Template/default values for containers
- Enforces min and max resource constraints per container
- If not specified, provides default request/limit values

### Key Commands:
```bash
# Check limit range
kubectl get limitrange
kubectl describe limitrange <limitrange-name>
```
