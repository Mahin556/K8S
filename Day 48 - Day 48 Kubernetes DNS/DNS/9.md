### 🔹 What is Anycast?

Anycast =
**Same IP address configured on multiple geographically distributed servers.**
Routing (BGP) sends users to the nearest/shortest path instance automatically.

Used by:

* Public DNS (8.8.8.8, 1.1.1.1)
* CDNs
* DDoS protection
* Large-scale APIs

---

# 🧠 How Anycast Works (Simple Flow)

1. Multiple servers advertise the **same IP prefix**.
2. Each server announces it via **BGP**.
3. Internet routers choose the **closest path**.
4. Users automatically reach nearest server.

No load balancer needed.

---

# ⚙️ How to Configure Anycast (Real Method)

Anycast requires:

* Public IP block
* ASN (Autonomous System Number)
* BGP capability
* Multiple data centers / VPS providers

---

## Step 1 — Get IP + ASN

You need:

* Public IP prefix (example: `203.0.113.0/24`)
* ASN from RIR (APNIC, ARIN, RIPE, etc.)
* Or use cloud provider with BGP support

---

## Step 2 — Configure Same IP on Multiple Servers

On each server:

```bash
ip addr add 203.0.113.10/32 dev lo
```

* Use `/32`
* Assign to loopback interface
* Do NOT assign to eth0 directly

---

## Step 3 — Install BGP Software

Common choices:

* FRRouting (FRR)
* BIRD
* ExaBGP

Example (FRR on Linux):

```bash
sudo apt install frr
```

---

## Step 4 — Configure BGP Advertisement

Example FRR config:

```
router bgp 65001
 bgp router-id 1.1.1.1
 neighbor <upstream-ip> remote-as <provider-asn>
 !
 address-family ipv4 unicast
  network 203.0.113.0/24
 exit-address-family
```

Each location advertises same prefix.

---

## Step 5 — Start BGP

```bash
sudo systemctl restart frr
```

Check:

```bash
vtysh -c "show ip bgp summary"
```

---

# ⚠️ Important Technical Notes

* Minimum routable prefix = usually /24 for IPv4
* Health checking must be implemented
* If a node fails:

  * Stop BGP advertisement
  * Traffic automatically shifts

Example health-based withdrawal:

```bash
ip route del 203.0.113.0/24
```

or disable BGP session.

---

# 🧪 How to Test Anycast

From different locations:

```bash
traceroute 203.0.113.10
```

Different paths = working anycast.
