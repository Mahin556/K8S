* 🔹 Check which DNS server your system is using

```bash
cat /etc/resolv.conf
```

* Look for lines like:

```
nameserver 8.8.8.8
nameserver 1.1.1.1
```

That is the DNS IP your system is using.

---

* 🔹 If using systemd-resolved (common in Ubuntu 20+)

```bash
resolvectl status
```

or

```bash
systemd-resolve --status
```

* It will show:

  * Current DNS Server
  * DNS Servers per interface

---

* 🔹 Quick one-liner (only nameserver IPs)

```bash
grep nameserver /etc/resolv.conf
```

---

* 🔹 On NetworkManager systems (RHEL / CentOS / Fedora)

```bash
nmcli device show | grep DNS
```
