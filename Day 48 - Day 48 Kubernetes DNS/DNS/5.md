Here are commonly used **public DNS resolvers** (you can configure them in NetworkManager, `/etc/resolv.conf`, router, or cloud VM):

---

* 🔹 **Google Public DNS**

  * IPv4:

    * `8.8.8.8`
    * `8.8.4.4`
  * IPv6:

    * `2001:4860:4860::8888`
    * `2001:4860:4860::8844`
  * Fast, reliable, widely used

---

* 🔹 **Cloudflare DNS**

  * IPv4:

    * `1.1.1.1`
    * `1.0.0.1`
  * IPv6:

    * `2606:4700:4700::1111`
    * `2606:4700:4700::1001`
  * Focus on privacy + speed

---

* 🔹 **Quad9 DNS**

  * IPv4:

    * `9.9.9.9`
    * `149.112.112.112`
  * IPv6:

    * `2620:fe::fe`
    * `2620:fe::9`
  * Blocks malicious domains (security-focused)

---

* 🔹 **OpenDNS (Cisco)**

  * IPv4:

    * `208.67.222.222`
    * `208.67.220.220`
  * Provides filtering and parental controls

---

* 🔹 **AdGuard DNS**

  * IPv4:

    * `94.140.14.14`
    * `94.140.15.15`
  * Blocks ads and trackers

---

### How to test a public DNS resolver

```bash
dig google.com @8.8.8.8
dig google.com @1.1.1.1
```

Compare query time:

```bash
dig google.com @1.1.1.1 +stats
```

---

### Which one should you use?

* For general use → `1.1.1.1` or `8.8.8.8`
* For security filtering → `9.9.9.9`
* For ad blocking → `94.140.14.14`
