## What is CoreDNS?

**Definition:** CoreDNS is the **internal DNS server** for Kubernetes that provides **service discovery by name**.

### Problem It Solves:
- Pod IPs are dynamic (change on restart)
- Services provide stable IPs, but IPs are still hard to manage
- Applications should use **names**, not IPs

### How It Works:
1. WordPress pod needs to connect to MySQL
2. Instead of using MySQL service IP, it uses the service **name**: `mysql-service`
3. CoreDNS resolves the name to the actual ClusterIP
4. Connection is established using the resolved IP

### CoreDNS vs External DNS:

| Feature | CoreDNS | External DNS |
|---------|---------|--------------|
| **Scope** | Inside cluster | Outside cluster (Internet) |
| **Resolves** | Service names to ClusterIPs | Domain names to External IPs |
| **Example** | `mysql-service` → `10.96.1.5` | `k.com` → `34.120.50.100` |
| **Used by** | Pods internally | External clients |
